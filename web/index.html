    Project Architecture & Viva Defense Guide

    01 / The 30-Second Elevator Pitch

    "Traditional inventory systems use mutable counters like UPDATE products SET stock = stock - 5, which causes race conditions and allows insiders to cover up theft. VaultStock solves this with an Immutable Append-Only Ledger where stock is dynamically derived via SUM(IN) - SUM(OUT), and every transaction is chained into a tamper-evident HMAC audit log just like Git commits."

    02 / Explaining the Security (The Git Analogy)

    Explain the audit log like Git commits: Each transaction stores the hash of the preceding transaction (prev_hash). Editing row #1 on disk changes its hash, breaking row #2's prev_hash link, which our 5-point verifier flags immediately.
